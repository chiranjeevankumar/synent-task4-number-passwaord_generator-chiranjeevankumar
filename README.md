
Project Description

This project is a simple Password Generator developed using Python. It generates a random password based on the length entered by the user.

Features

- Generates random passwords
- Includes uppercase letters
- Includes lowercase letters
- Includes numbers
- Includes special characters
- Lets the user choose password length (minimum 4)
- Uses a Python function to generate the password

Technologies Used

- Python 3
- random module
- string module

How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run "python Password_generation.py".

Example Output

Enter password length (minimum 4): 8
Generated Password: (a random 8-character password)

The generated password will vary each time.
