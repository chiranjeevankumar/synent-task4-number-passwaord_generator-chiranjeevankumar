Password Generator

Project Description

This project is a simple Password Generator developed using Python. It generates a random password based on the length entered by the user.

Features

- Generates random passwords
- Includes uppercase and lowercase letters
- Includes numbers
- Allows the user to choose the password length
- Uses a Python function to generate the password

Technologies Used

- Python 3
- random module
- string module

How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the following command:

python password_generator.py

Example Output

Enter password length: 8
Generated Password: aB7kP2xM

The generated password will vary each time.
